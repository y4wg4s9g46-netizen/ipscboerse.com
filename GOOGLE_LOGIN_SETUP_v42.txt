GOOGLE LOGIN SETUP – IPSC Börse v42

Code-Seite:
- Google Login ist in auth.js fertig angebunden über:
  supabase.auth.signInWithOAuth({ provider: "google" })
- Redirect bleibt auf der aktuellen Seite, z.B.:
  https://ipscboerse.com/marktplatz.html

   https://ipscboerse.com

4. Authentication → Providers → Google aktivieren
5. Google Client ID und Google Client Secret eintragen

Google Cloud / Google Auth Platform:
1. OAuth Client ID erstellen
2. Application type: Web application
3. Authorized JavaScript origins:
   https://ipscboerse.com
4. Authorized redirect URIs:
   https://huprxirlthkisjngwash.supabase.co/auth/v1/callback
5. Client ID und Secret kopieren und in Supabase eintragen
