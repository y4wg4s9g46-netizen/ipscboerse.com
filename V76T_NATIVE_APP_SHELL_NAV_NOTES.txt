V76T_NATIVE_APP_SHELL_NAV_NOTES
=================================

Ziel:
- Hauptnavigation in der nativen Capacitor-App ohne harten HTML-Reload.
- Browser/Desktop bleibt bei normalen HTML-Seiten.
- Kein schweres Framework, keine großen Content-Umbauten.

Umsetzung:
- native-shell.html + native-shell.js neu.
- In Capacitor (capacitor:// / ionic://) routen Hauptseiten automatisch in die Native Shell.
- Die Shell bleibt als ein WebView-Dokument stehen und lädt bekannte Seiten in same-origin iframes.
- Header/Bottom-Bar bleiben im Parent stehen; Header/Bottom der geladenen Seiten werden im iframe ausgeblendet.
- Interne Links der geladenen Seiten werden auf Parent-Routing umgebogen.
- Bereits besuchte Tabs bleiben geladen; HTML wird zusätzlich vorsichtig per fetch vorgewärmt.
- Theme wird im Parent gehalten und in Frames gespiegelt.
- Service Worker Cache auf v76t mit App-Shell-Assets erweitert.

Sicherheitsgrenze:
- Keine Supabase-Tabellen geändert.
- Browser/Website bleibt weiterhin normale Multi-Page-Seite.
- Native Shell ist nur für App-Hauptseiten aktiv und kann per ?nativeShell=0 übersprungen werden.
